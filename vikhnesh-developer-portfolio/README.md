# Vikhnesh B S — Developer Portfolio

A responsive static portfolio website based on the supplied Power Apps and K2 Developer résumé.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder next to it so the résumé download works.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new **public** repository, for example `vikhnesh-portfolio`.
3. Upload `index.html` and the `assets` folder (including `Vikhnesh-BS-Resume.pdf`) to the repository root.
4. Open the repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub will display your website URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/vikhnesh-portfolio/`
   Replace the username with your own. The actual URL is assigned by GitHub after publishing.
8. Open the URL on mobile and desktop and test the résumé download and contact links.

## Before sharing with recruiters
- Check your contact details and dates.
- If you prefer not to publish your phone numbers publicly, remove the phone links from `index.html` before uploading.
- Add your LinkedIn profile URL when ready.
- This website does not collect form submissions or use tracking.
